ZERO HOUR: TACTICAL BREACH is a 3v3 bomb-defusal tactical FPS in three.js. Attackers plant the Spike at Site A (Server Vault) or Site B (Reactor Core) while defenders hold angles and defuse — first to 5 rounds takes the match. Full bot squads run a finite-state AI (hold, patrol, investigate, engage, flank, plant/defuse), with a buy phase and economy, halftime side swap, spectator camera, and mobile touch controls.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
